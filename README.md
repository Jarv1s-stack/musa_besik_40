Қонақтың қатысу жауабы мен ақ тілегі WhatsApp-та **+7 775 318 7632** нөмірінің чатына дайын мәтін болып ашылады. Қонақ мәтінді қарап, WhatsApp ішіндегі «Жіберу» батырмасын өзі басады. Көшіру батырмасы да бар.

Жыл көрсетілмегендіктен, күн 2026 жылғы 1 қараша деп қойылды.
